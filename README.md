# Personal Finance Tracker (PFT)

A REST API for personal finance management built with Java Spring Boot. The system allows users to manage multiple accounts, perform transactions, and maintain a full financial history.

## Features
- Deposit and withdraw money across multiple accounts
- Full transaction history logging
- Revert the most recent transaction
- Create and delete multiple financial accounts
- JWT-based authentication for secure access

## Tech Stack
- Backend: Java, Spring Boot
- Database: H2 Database (in-memory)
- API documentation: Swagger UI 

## Running the Project
```bash
cd pft-backend
./mvnw spring-boot:run
```
API docs available at: `http://localhost:8080/swagger-ui.html`
